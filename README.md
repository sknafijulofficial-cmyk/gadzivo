# Gadzivo

Local Flask e-commerce website with product browsing, customer accounts, cart, Cash on Delivery checkout, and admin management.

## Run it

1. Open this folder in VS Code.
2. Install dependencies: `pip install -r requirements.txt`
3. Start it: `python app.py`

The database and demo products are created automatically. Your browser opens once at `http://127.0.0.1:5000`.
